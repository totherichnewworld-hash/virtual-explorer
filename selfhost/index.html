配置 Google Maps API Key

  1. 去 Google Cloud Console 新建项目，启用 Map Tiles API。
  2. 创建 API key，务必加两道限制：应用限制选 HTTP referrer 填你的域名； API 限制只勾 Map Tiles API。
  3. 在 APIs & Services → Quotas 给 Photorealistic 3D Tiles 设每日上限， 再到 Billing → Budgets 设一个预算告警。
  4. 本地：把 config.example.js 复制成 config.js，填进去。
    线上：在 Cloudflare Pages 设环境变量 GOOGLE_MAPS_API_KEY， 本页会从 /api/key 取。

额度：Photorealistic 3D Tiles 每月前 1,000 次 root tile 请求免费， 之后约 $6 / 1,000 次，一次请求可撑 3 小时以上的瓦片拉取 —— 个人用基本落在免费额度内。 但 key 一旦裸奔被人刷，账单是你的，所以上面第 2、3 步别跳过。

读不到 key 时这页就停在这里，不会偷偷发请求。
