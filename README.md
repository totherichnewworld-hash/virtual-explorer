# 街区兑换所 · Virtual Citywalk

把室内活动换算成真实城市路线上的步行距离。

原地踏步 5 分钟 = 500 步 = 360 米；里斯本 Cais do Sodré 到山上圣母观景台正好 3,400 米。
一步一步兑换，直到把整条路走完。

## 里面有什么

- **6 座城市，6 条真实路线**：里斯本、京都、伊斯坦布尔、纽约、雷克雅未克、布宜诺斯艾利斯。
  每条路线的站点与距离取自真实街道走法。
- **程序生成的街景**：Canvas 逐帧生成立面（葡式瓷砖、京都町屋格子、褐石消防梯、冰岛波纹铁皮…）、
  路灯、电车线、行道树、铺装花纹；走路时画面有轻微起伏。
- **按城市当地时间渲染天空**：用 `Intl` 取该城时区的真实时刻，所以你可能在深夜走进里斯本的下午。
- **街角瞬间**：每个街区有机会遇到一段由该城市素材组合的见闻，可以收进手账；
  接入 `sample` 能力后还能让 Claude 现写一张明信片。
- **手账**：站点戳、明信片、累计公里数、连续天数。进度存在 artifact 的 `db` 里。

## 结构

单文件 `index.html`：CSS token（双色 riso 印刷风，明暗双主题）→ 城市数据 →
街景渲染器 → 模拟循环 → 面板与存档。无外部依赖，字体走 Google Fonts。
